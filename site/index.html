TaskTimer

Um timer de tarefas para o desktop. Acompanhe o tempo de cada atividade, veja o progresso em relação à estimativa e mantenha o histórico — com os dados salvos no seu computador.

Os instaladores serão publicados no primeiro GitHub Release. Enquanto isso, os botões levam à página de releases. pré-release

Verificação de integridade (SHA256)

Depois de baixar, compare o hash do arquivo com a lista oficial do release. Assim você confirma que o instalador não foi alterado no caminho.

Hashes disponíveis após o primeiro release


          

            Abrir SHA256SUMS no GitHub Releases
          

        


        
Como verificar

        

          

            
Linux ou macOS

            
No diretório do arquivo baixado, com o manifesto SHA256SUMS:

            
sha256sum -c SHA256SUMS

            
Ou calcule o hash de um arquivo específico e compare com a lista:

            
sha256sum TaskTimer_0.1.0_amd64.AppImage

          

          

            
Windows (PowerShell)

            
Calcule o SHA256 e compare o resultado com o valor publicado:

            
Get-FileHash -Algorithm SHA256 .\TaskTimer_0.1.0_x64-setup.exe
